# Ghostwriter

Ghostwriter is a libre Android app for writing rap lyrics.

The app combines a lyric editor, local projects, beat playback, and dictionary
search. See [Features](documentation/FEATURES.md) for implemented and planned work.

## Getting started

Choose a lyric folder on Home before creating or opening a project.
Use **Settings → Choose lyric folder** to reconnect or change the folder.
See [Project storage](documentation/README.md#project-storage) for recovery,
uninstall behavior, and save failures.
